# CLAUDE.md

Guidance for AI agents (Claude Code) working in this repository.

## Project

**Anten VN** — open-source, Vietnamese-only PWA that helps users find DVB-T2 TV towers in Vietnam and aim antennas using the phone compass.

- Live: <https://anten-tv.github.io/> (GitHub Pages, repo `anten-tv/anten-tv.github.io`, Vite `base: "/"`)
- Code license: MIT (`LICENSE`). Data license: CC BY 4.0 (`DATA-LICENSE`).
- All UI strings are Vietnamese, single locale, in `src/lib/i18n/vi.ts`.

## Commands

```bash
npm run dev            # Vite dev server, port 4123
npm run build          # tsc -b && vite build
npm test               # Vitest (unit tests in src/lib/*.test.ts)
npm run validate-data  # Validate data/towers.json against schema + project rules
node scripts/generate-coverage.mjs [tower-id ...]  # Regenerate coverage polygons (default: all)
```

**After any change to `data/towers.json`, always run `npm run validate-data`. After code changes, run `npm test`.**

## Architecture

React 19 + TypeScript + Vite + MapLibre GL + vite-plugin-pwa (Workbox). No backend.

- `src/main.tsx` — entry; registers service worker, offline-ready toast
- `src/App.tsx` — 3-view SPA with tab navigation: map / list / aim
- `src/config.ts` — canonical data URLs (raw.githubusercontent.com), OpenFreeMap style URLs, map defaults
- `src/types.ts` — `Tower`, `Mux`, `Operator`, `Province`, `TowersFile`
- `src/components/` — `MapView` (MapLibre, markers, coverage, label masking), `TowerList`, `TowerDetailSheet`, `AimView`, `CompassDial`, `CalibrationPrompt`, `ManualLocationPicker`, `Onboarding`, `OfflineBadge`
- `src/hooks/` — `useGeolocation` (caches last fix in localStorage), `useHeading` (device orientation, iOS/Android quirks), `useTowers` (bundled snapshot + remote stale-while-revalidate)
- `src/lib/` — `data.ts` (load/validate towers + coverage), `geo.ts` (haversine distance/bearing), `freq.ts` (channel→MHz), `heading.ts` (magnetic→true, sensor correction), `operators.ts` (operator color palette)
- `scripts/` — Node .mjs tools: `validate-data.mjs`, `generate-coverage.mjs`, `generate-vn-boundary.mjs`, `ingest-kmz.mjs` (KMZ → draft tower JSON, human-curated)
- `docs/research/` — per-source research notes (sdtv, thvl, lapdattruyenhinhkts)

## Critical invariants — do not break

### 1. No-redeploy data flow

`data/towers.json` is a single hand-editable file. The app fetches it live from `raw.githubusercontent.com` (stale-while-revalidate via Workbox), so **data PRs go live without a redeploy**. A build also bakes a snapshot as offline fallback. Never move tower data into code, never require a rebuild for data changes, and keep `src/lib/data.ts` validation lenient-but-safe: an invalid remote file must be rejected and fall back to the bundled snapshot, never crash installed clients.

### 2. Frequency is never stored

Frequency is always derived: **MHz = 306 + 8 × channel**. Do not add a frequency field to data, schema, or types. Conversion lives in `src/lib/freq.ts`.

### 3. No copyrighted imagery

Operator coverage map images (PNGs, KMZ GroundOverlays) are copyrighted — **never commit them**. Coverage polygons in `data/coverage/*.geojson` are our own terrain line-of-sight estimates from `scripts/generate-coverage.mjs` (AWS Terrain Tiles / SRTM). The giaGA repo has no LICENSE → facts-only extraction (coordinates, channels), no file copies.

### 4. Sensor events never enter React state

Compass/orientation events fire at ~60 Hz. They must **never** call `setState` directly — use the subscribe + `requestAnimationFrame` pattern (see `useHeading.ts` and `CompassDial.tsx`). Rendering reads the latest value inside rAF.

### 5. Label rules (basemap)

- Basemap labels outside Vietnamese territory are hidden via `["within", polygon]` filters on all symbol layers — see `MapView.applyVnLabelMask` and `public/vn-boundary.json` (generated by `scripts/generate-vn-boundary.mjs` from Natural Earth 10m **Vietnam-POV** file; includes Hoàng Sa/Trường Sa, buffered islets, coastal sea band, curated `EXTRA_ISLANDS`).
- Labels are forced Vietnamese: `name:vi` → fallback `name:latin`, **never raw `name`** (leaks CJK).
- Archipelago areas: cloned `-vnisl` layers show only features with `["has","name:vi"]`, plus a `BLOCKED_NAMES` list (Tam Sa / Sansha / Kalayaan). Foreign administrative labels must never surface there.

## Data rules (`data/towers.json`)

- Top level: `{ "version": 1, "updated": "YYYY-MM-DD", "towers": [...] }`. Keep towers **sorted by `id`**; bump `updated` on every data change.
- `id` is an immutable unique slug. Coordinates within Vietnam bounds (lat 8.1–23.5, lon 102–110.5). Channels 21–48.
- `province` uses **post-2025 slugs** (2025 admin reform merged 63→34 provinces); `data/aux/provinces.json` maps `oldNames`. Original addresses go in `addressOld`.
- Always cite `source` / `sourceUrl` / `sourceDate`. `verified: true` only with screenshot, official document, or real reception report — seed data (KMZ vintage 2017–2023) is all `verified: false`.
- **VTC terrestrial shut down 01/2025**: any VTC mux must be `status: "inactive"`.
- Known gaps for future contributions: mountainous north, Central Highlands, DTV/RTB coordinates, AVG, polarization (currently null everywhere).
- After adding/moving a tower, regenerate its coverage: `node scripts/generate-coverage.mjs <tower-id>`.
- Validation messages in `scripts/validate-data.mjs` are intentionally in Vietnamese (shown on PR checks) — keep them so.

## Documentation upkeep — required

**After every code or data change, update the affected docs in the same commit/PR.** Specifically:

- `README.md` — features, tech stack, setup, accuracy notes
- `CONTRIBUTING.md` — schema fields, data rules, contribution workflow (must stay in sync with `data/schema/towers.schema.json` and `validate-data.mjs`)
- `docs/research/*.md` — when a data source is added, re-checked, or found dead
- `data/SOURCES.md` — provenance for any new data
- This `CLAUDE.md` — when architecture, commands, or invariants change

Stale documentation is treated as a bug. If you change behavior and the docs still describe the old behavior, the task is not done.

## Conventions

- TypeScript strict; React function components + hooks only.
- User-facing text: Vietnamese with proper diacritics, added to `src/lib/i18n/vi.ts`, never hardcoded in components.
- MapLibre is lazy-loaded; keep the initial bundle lean (manual chunk for react vendor is configured in `vite.config.ts`).
- PWA/offline first: any new remote resource needs a Workbox caching strategy in `vite.config.ts` and a sensible offline fallback.
